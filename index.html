Cloud Sync — Settings

Connection details are saved on this device only. Set up the same details on every device that should share recipes. You can use Apps Script, Supabase, or both (one is a live backup of the other).

Google Apps Script
Supabase

How to set up the cloud (one time)
  1. Apps Script: create a Google Sheet → Extensions → Apps Script → paste apps-script/Code.gs → run setupSyncToken once (copy the token from the log) → Deploy → New deployment → Web app, Execute as Me, Who has access Anyone → copy the /exec URL here.
  2. Supabase: new project → SQL Editor → run supabase/schema.sql (change the sync key on its last lines first) → Project Settings → API: copy the Project URL and the anon / publishable key here, with your sync key.
  3. Press Test connection, then Save sync settings. On every other device: open the app → Restore from cloud on the first screen, or sign in and enter the same details here.
